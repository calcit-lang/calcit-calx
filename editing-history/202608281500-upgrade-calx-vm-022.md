# 升级 Calx VM 0.2.2 / Upgrade Calx VM 0.2.2

## 中文

- 升级到 `calx_vm 0.2.2`，获取 M0 语义安全、类型化 validator 和 boxed `CalxError` snapshot。
- 升级共享 raw ABI crate 至 `calcit_native_ffi 0.1.2`，C ABI 继续保持 v1。
- CI 验证声明的最低兼容版本 Calcit 0.13.57；另在本地使用 0.13.58 完成真实动态库 runtime 验证。

## English

- Upgrade to `calx_vm 0.2.2` for M0 semantic safety, the typed validator, and boxed `CalxError` snapshots.
- Upgrade the shared raw ABI crate to `calcit_native_ffi 0.1.2` while keeping C ABI v1 unchanged.
- Keep CI on the declared Calcit 0.13.57 minimum; separately verify the real dylib runtime locally with 0.13.58.
