# C-safe buffer v1 migration

- Migrated `run_vm` from the Rust-layout-dependent dylib ABI to synchronous buffer protocol v1.
- Added strict request/output boundary validation, panic containment, and adapter tests.

- Structurally migrated the legacy `get-dylib-ext` macro schema with Calcit 0.13.51 and stopped hiding `calcit.cirru` diffs.
