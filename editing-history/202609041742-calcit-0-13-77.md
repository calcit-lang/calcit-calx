# Calcit 0.13.77 upgrade / 升级记录

Timestamp / 时间：2026-09-04T17:42:40Z

## 中文

- 将声明的 Calcit 工具链基线从 0.13.64 升级到已发布的 0.13.77。
- CI 改用维护中的 `calcit-lang/setup-calcit@v1`，由 `deps.cirru` 选择 Calcit 版本，同时继续安装独立版本的 caps。
- 保持模块版本 0.0.6、依赖图、C-safe buffer protocol v1、Calx VM 转换边界与运行语义不变。
- 使用 release dylib、FFI trace、严格依赖检查、Calcit 静态检查和 Rust 全套门禁验证兼容性。

## English

- Upgrade the declared Calcit toolchain baseline from 0.13.64 to the published 0.13.77 release.
- Move CI to the maintained `calcit-lang/setup-calcit@v1` line, selecting Calcit from `deps.cirru` while continuing to install independently versioned caps.
- Keep module version 0.0.6, the dependency graph, C-safe buffer protocol v1, Calx VM conversion boundary, and runtime semantics unchanged.
- Validate compatibility with the release dylib, FFI tracing, strict dependency checks, Calcit static checking, and the full Rust gate.
