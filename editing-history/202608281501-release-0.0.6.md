# 发布 0.0.6 / Release 0.0.6

## 中文

- 同步 Cargo crate 与 Calcit 模块版本为 0.0.6。
- 发布 `calx_vm 0.2.2` 与 `calcit_native_ffi 0.1.2` 的消费端迁移。
- 保持 Calcit 0.13.57 最低兼容要求和 buffer-v1 C ABI 不变。

## English

- Synchronize the Cargo crate and Calcit module versions at 0.0.6.
- Release the consumer migration to `calx_vm 0.2.2` and `calcit_native_ffi 0.1.2`.
- Preserve the Calcit 0.13.57 minimum and the buffer-v1 C ABI.
